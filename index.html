TDX API 金鑰

到 tdx.transportdata.tw 免費註冊會員，登入後在「會員中心 → 資料服務 → API 金鑰」取得 Client Id 與 Client Secret。金鑰只存在這支手機的瀏覽器裡。每次查詢只用 1 次額度，免費方案每月約 3,000 次。
